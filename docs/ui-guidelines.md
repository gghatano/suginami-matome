# 画面づくりの決まりごと

どちらのサイトも、HTML・CSS・JavaScript を1つのファイル（`index.html`、`jidoukan/index.html`）にまとめています。ライブラリやビルドの工程はありません。

## 1. レイアウトがずれない

**中身によって出たり消えたり、長さが変わったりするものは、その場所を先に確保する。** 児童館カレンダーでは、同じ種類のずれを何度も直してきました。

| 起きたこと | 原因 | 対処 |
|---|---|---|
| 申込カードが0件のとき、下の設定とカレンダーが上にずれた | 0件で欄が1行に縮んだ | 欄の高さを固定し、0件でも同じ高さの枠に「0件」と出す |
| Windows でカードがはみ出したときだけ下がずれた | 横スクロールバーが出た分、欄が高くなった | `overflow-x: scroll` でスクロールバーの場所を常に確保 |
| 見出し横の注記が、件数が長いと2行になった | 注記が見出しと同じ行にあった | 注記を独立した1行にして、表示しないときも高さを確保（`visibility: hidden`） |
| 施設を足したら、カードが伸びて下がずれた | 高さを「最小」でしか決めていなかった | 高さを固定し、カードの各項目の行数を決めた（あふれる分は「…」、全文はマウスを乗せると出る） |

確かめるときは、件数（0・1・多数）、表示・非表示、PC とスマホ、スクロールバーが幅を取る表示（Windows）と重ねる表示（Mac・スマホ）の組み合わせで、要素の位置を測ります。Playwright で `--hide-scrollbars` を外すと、Windows 相当の表示になります。

## 2. 最初の画面に大事なものを入れる

- PC（1280×800）で、開いたときにカレンダーの1週目まで見える
- 上部は「申し込める行事 → 表示の設定 → カレンダー」の順に並べる。いちばん大事なのは受付開始日を見逃さないこと
- 縦に長くなる要素（申込カード）は横1列にして、横にスクロールさせる

## 3. 色

- 色はすべて CSS 変数（トークン）で定義する。ライトとダークの両方に値を持たせる（`prefers-color-scheme` と、`data-theme` による手動の切り替えの両方に対応）
- 児童館カレンダーの**チップの色は施設を表す**（`--f1`〜`--f6`。`sources.json` の並び順で割り当てる）。対象（小学生以上／乳幼児）は色で分けない。同時に両方を見る使い方をしないため、上の絞り込みで切り替える
- オレンジ（`--open`）は「申込」にだけ使う（受付開始のチップ、受付中の枠）
- 休館は灰色（`--closed-soft`）。施設の一部だけが休みのときは、休む施設の色で「休」と出す
- 終わった週は不透明度 0.4 で薄くする

7館目を足すと、1館目と同じ色になります。館がさらに増えるなら、色ではなく館名の表示で見分ける形に切り替えます。

## 4. 幅の区切り

| 幅 | 扱い |
|---|---|
| 761px 以上 | PC・タブレット。マス目に行事名まで出す（iPad も縦向きを含めてここ） |
| 760px 以下 | スマホ。日ごとの一覧が初期表示。マス目表示に切り替えると、点と「休」「申」だけを出す |
| 520px 以下 | 細かい詰め（短い施設名、余白、2行に回す見出し） |

## 5. 文言

- 日本語は「です・ます」。ボタンは何が起きるかをそのまま書く（「この設定のURLをコピー」）
- 時刻は 24 時間表記（おたよりの「4:00」は 16:00 と出す）
- 原本と食い違う可能性がある情報には、原本 PDF へのリンクを付ける（自動で読み取っているため）
