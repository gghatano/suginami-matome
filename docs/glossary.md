# 用語集

このドキュメントに出てくる言葉を、初めての人向けに説明します。五十音順ではなく、関係する言葉が近くに並ぶようにしています。

## Git と GitHub

| 言葉 | 意味 |
|---|---|
| リポジトリ | プロジェクトのファイル一式と、その変更の履歴をまとめて保管する場所。ここでは `gghatano/suginami-matome` |
| コミット | 変更をひとまとまりにして履歴に記録すること。また、その記録 1件 |
| ブランチ | 履歴の枝分かれ。本番の内容（`main`）に影響を与えずに、別の枝で作業を進められる |
| `main` | 本番に出ている内容のブランチ。ここが変わると本番サイトが更新される |
| `develop` | 本番に出す前の内容をためておくブランチ。GitHub Pages で確認できる。**消さないこと** |
| 作業ブランチ | 1つの作業のために `develop` から切るブランチ。例：`claude/docs-diataxis` |
| push | 手元のコミットを GitHub に送ること |
| PR（プルリクエスト） | 「このブランチの変更を、あのブランチに取り込んでください」という依頼。変更の差分が一覧でき、確認やコメントができる |
| マージ | PR の変更を取り込むこと。作業ブランチ → `develop` → `main` の順に取り込む |
| head / base | PR の「取り込まれる側（変更のあるブランチ）」と「取り込む側（向き先）」 |
| Issue | やること・困りごとのメモを GitHub 上に残すもの。例：#47 |

## 自動処理とサイトの公開

| 言葉 | 意味 |
|---|---|
| GitHub Actions | GitHub 上で、決まった時刻やきっかけでプログラムを動かす仕組み |
| ワークフロー | GitHub Actions で動かす処理の設定ファイル。`.github/workflows/` にある `fetch.yml`（記事集め）、`pages.yml`（Pages の公開）、`jidoukan.yml`（API 版の読み取り） |
| cron | 「毎日 23:00」のような定期実行の時刻の書き方 |
| Cloudflare Workers | 本番サイトを配信しているサービス。`main` が更新されると自動で作り直される |
| プレビュー URL | PR ごとに Cloudflare が作る確認用のアドレス。PR に bot がコメントで知らせる |
| GitHub Pages | GitHub が提供するサイト公開の仕組み。ここでは `develop` の確認用と、このドキュメントの公開に使う |
| デプロイ | 新しい内容をサイトに反映すること |

## データと処理

| 言葉 | 意味 |
|---|---|
| JSON | データをテキストで書く形式。`{"title": "...", "date": "2026-11-21"}` のように書く |
| スクレイパー | Web サイトを読みに行き、必要な情報（記事のタイトルやリンク）を取り出すプログラム。`scrapers/` にある |
| RSS | サイトが新着記事を一覧で配っている形式。スクレイピングより取り出しやすい |
| おたより | 児童館などが毎月出す、行事の予定を書いた PDF。区のサイトに載る |
| キャッシュ | 一度読み取った結果を保存しておくもの。同じ PDF を二度読まずに済む。`data/jidoukan/extracted/` |
| sha256 | ファイルの中身から計算する「指紋」のような文字列。中身が1文字でも変われば別の値になるので、PDF が差し替わったかを見分けるのに使う |
| 省略済み（skipped） | 対象の月が終わったおたよりを、読み取らずに「見た」とだけ記録したもの |
| 申込制 | 事前の申込が必要な行事。受付開始日を見逃さないことが、児童館カレンダーのいちばんの目的 |

## Claude まわり

| 言葉 | 意味 |
|---|---|
| Claude Code | このリポジトリの開発を手伝う AI。コードを読み書きし、PR を作る |
| `CLAUDE.md` | Claude Code が作業を始めるときに自動で読む、このリポジトリの約束ごと |
| セッション | Claude Code との1回の作業の会話。クラウドで動くものはコンテナ（作業用の一時的な環境）の中で動く |
| スケジュールしたタスク | 決まった時刻に Claude のセッションへ依頼を送る仕組み。児童館カレンダーの定期更新に使っている |
| 専用セッション | 児童館カレンダーの定期更新だけを受け持つセッション「児童館カレンダー週次更新（専用）」 |

## 画面

| 言葉 | 意味 |
|---|---|
| チップ | カレンダーのマスに並ぶ、行事1件ぶんの小さな札 |
| 申込カード | 「これから申し込める行事」に並ぶカード |
| ダークモード | 黒っぽい背景の表示。ブラウザや OS の設定、または画面右上のボタンで切り替わる |
| レイアウトのずれ | 件数や表示の有無によって、下の要素の位置が動いてしまうこと。このリポジトリでは避ける決まり（[画面づくりの原則](explanation/ui-principles.md)） |
