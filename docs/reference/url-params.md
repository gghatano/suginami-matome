# 児童館カレンダーの URL と保存値

## URL パラメータ

URL の `?` のあとに付けると、その状態で開きます。よく見る表示をブックマークしたり、家族に送ったりするのに使います。

```
/jidoukan/?center=honan&target=baby&regular=1&view=month
```

| パラメータ | 値 | 省略したとき |
|---|---|---|
| `center` | 施設の `key`。複数はカンマ区切り（`honan,plaza_izumi`） | 全館 |
| `target` | `kids`（小学生以上）／`baby`（乳幼児親子） | すべて |
| `regular` | `1` で毎日・毎週のプログラムも出す | 出さない |
| `month` | `YYYY-MM` | 今月（おたよりがなければ直近の号の月） |
| `view` | `month` でスマホもマス目（カレンダー）表示にする | 日ごとの一覧（PC は常にマス目） |

決まりごとです。

- パラメータが1つでもあれば、**URL だけで表示を決める**。ブラウザに保存した選択は使わず、書かれていない項目は初期値になる（送った人と受け取った人で、同じ画面になるように）
- パラメータがなければ、ブラウザに保存した選択で表示する
- 画面で選び直すと、アドレス欄の URL もその状態に書き換わる。「この設定のURLをコピー」でそのまま取れる
- 存在しない値は無視する。古い形式の `#m202611` も読む

## ブラウザに保存するもの（`localStorage`）

| キー | 内容 |
|---|---|
| `jdk-off` | 外した施設の一覧。外したものだけを覚えるので、あとから増えた施設は最初から表示される |
| `jdk-filt` | 対象（すべて／小学生以上／乳幼児親子） |
| `jdk-reg` | 毎日・毎週のプログラムを出すか |
| `jdk-view` | スマホの表示（一覧／カレンダー） |
| `theme` | ダークモード。まとめサイト・ドキュメントと共通 |
